## 已知限制與下一步

- 沒有實體iPhone結果。請在Cloudflare Preview實測單指拖曳、雙指縮放、插旗、選點返回與長時間遊玩；WebKit模擬不能代表真實Safari的裝置負載。
- 50題約十天就能看過，多樣化不能無限消除熟悉感。日表210天循環；後續持續補可靠且不同場址的非棒球體育與北部文化題，擴庫後重編譯並重跑長期測試。
- 座標是官方代表點或概略場址，未保證入口、全事件範圍或測量精度。圖資為2021快照，非最新法定界線；難度待真人校準。
- 無帳號同步；收藏與足跡來自本機最近365筆每日紀錄，自由練習不計入收藏或連勝。清除資料或換裝置不保留。
- 部分官方頁可能對讀者要求驗證；可讀性掃描不能代替人工史料稽核。

先驗收Preview與實機，再由使用者決定是否「上線」。
