# v3.1 驗收摘要

基準：正式v3.0 main `487959c`；功能分支 `feature/v3.1-product-sprint`。

## 已通過

- **10個單元測試**：臺灣換日、每日固定種子、730日期的五區覆蓋／三難度／至少三類主題／同類上限／棒球上限、全45題輪替、來源與定位契約、計分、v2/v3續玩、壞檔／null答案、儲存額度錯誤、歷史去重與streak。
- **133項瀏覽器斷言**：Chromium 65、WebKit 65，加Chromium真觸控拖曳／pinch／恢復捲頁3項。包含桌面五題與手機五題、插旗確認、唯讀答案地圖、知識卡與定位來源、重新整理續玩、結算、故事回顧、歷史複習、分享fallback、跨午夜、GitHub Pages子路徑、缺圖資fallback、320/375/430px首頁與手機遊戲無水平溢位。
- 手機全螢幕對話框：背景inert、Tab／Shift+Tab循環、Esc返回、焦點還原、縣市捷徑。
- axe自動WCAG A/AA：兩種瀏覽器的桌面與手機對話框均為0違規。這不等於完整人工無障礙認證。
- 靜態建置成功；所有資源相對路徑，無登入、無後端；CI上傳測試JSON與首頁／地圖／答題／總結截圖。

## 來源稽核

新增24題皆逐頁讀取及編輯核對，原21題保留既有稽核，世大運來源另修補。全庫史料／座標52個不同網址：50個自動直讀成功、2個高雄官方頁遇防爬403，另以公開web reader核對內容。見 [逐題稽核](QUESTION-AUDIT.md) 與 [可讀性掃描](SOURCE-CHECK.json)。HTTP成功不等於史實自動查證。

## 效能比較

相同Chromium iPhone 13模擬、localhost、全新瀏覽器環境：首頁資源約597KB→130KB（約減78%），詳細圖資512,094 bytes→0，地圖path 441→7；遊戲開始、首次放大前的鄉鎮path 368→0。詳見 [原始量測](PERFORMANCE.json)。

## 已知限制與建議驗收

- 沒有實體iPhone測速數據；WebKit模擬不等於實際Safari、記憶體壓力與網路環境。請在預覽站實測拖曳、雙指縮放、選點返回及讀卡。
- 官方代表點與概略場址不保證入口或測量精度；圖資為2021快照，非最新法定界線。難度仍待真人校準。
- 無帳號同步。擴充後尚未開局的當日日題可能更換，已儲存的合法題組保留。
- 手機瀏覽器測試的pinch為Chromium觸控事件；WebKit驗證完整選點流程、縮放按鈕、全螢幕及焦點。
- 高雄兩個官方頁可能向讀者要求瀏覽器驗證。排程連結檢查應將防爬與真失效分開處理。
